# filter_contenttranslator — Documentation

Render-time filter of the **Content translator** plugin family by [Wunderbyte GmbH](https://www.wunderbyte.at).
It shows each user the stored translation of registered content in their language. Everything about
creating, reviewing and paying for translations lives in
[local_contenttranslator](https://github.com/Wunderbyte-GmbH/moodle-local_contenttranslator/tree/main/docs).
